# ADR-011: i18n pt/en com detecção do browser

## Status

Accepted — 2026-08-24

## Context

A constituição pedia locale MVP só pt-BR. Visitantes com browser em inglês (e outros idiomas) viam UI só em português, sem opção de escolha.

## Decision

1. Suportar **dois** locales de UI: `pt` e `en`.
2. Catálogo TypeScript em `shared/i18n` (sem lib i18n externa no MVP).
3. Auto-detect: `pt*` → `pt`, caso contrário → `en`; override em `localStorage`.
4. Manter rotas URL em português (`/ferramentas`, etc.); só o copy muda.
5. Atualizar princípio de locale na constituição para “pt + en”.

## Consequences

- Melhor alcance internacional sem mudar arquitetura front-only
- Catálogo de strings a manter em sync
- SEO hreflang / rotas bilíngues ficam para `011` se necessário
